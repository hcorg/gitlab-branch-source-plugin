Determines which branches are discovered.
Only branches that are not also filed as MRs
If you are discovering origin merge requests, it may not make sense to discover the same changes both as a merge request and as a branch.
Only build MRs (suppress branch builds for branches filed as MRs)
Branches that are filed as a merge request will not be built as branches — only the merge request head is built. This avoids duplicate builds when origin merge request discovery is also enabled. Branches matching the "Branches to always include" regex are exempt and will still be built as branches regardless.
All branches
Ignores whether the branch is also filed as a merge request and instead discovers all branches on the origin project.
